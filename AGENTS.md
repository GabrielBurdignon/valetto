# VALETTO

- Interface e comunicação em português brasileiro. Marca em pré-operação em Belo Horizonte.
- Não inventar atendimentos, métricas, avaliações, condições comerciais ou garantias operacionais.
- App Router com Server Components por padrão; isolar interatividade em componentes client.
- TypeScript strict. Conteúdo compartilhado em `src/lib`, componentes em `src/components`, tokens em `src/app/globals.css`.
- Preservar navegação por teclado, contraste, mobile e `prefers-reduced-motion`.
- Não simular envio de leads. Exigir backend configurado, validação e consentimento antes de habilitar formulário.
- Não representar composições gráficas como modelos reais de moto. Modelo 3D exige licença, proporções e procedência verificadas.
- Instalar dependências com npm; manter package-lock.json. Node >=20.9 (ambiente validado com Node 24).
- Validar alterações com `npm run lint`, `npm run typecheck`, `npm run build` e testes relevantes.
- Este ambiente já é isolado. Usar o checkout existente; não criar worktrees sem pedido explícito.
